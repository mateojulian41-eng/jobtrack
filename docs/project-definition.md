# Definición del proyecto JobTrack

## Problema

Las personas que están buscando empleo aplican a múltiples vacantes y pueden perder el control de las empresas, cargos, fechas, plataformas y estados de cada proceso.

## Público objetivo

Estudiantes, practicantes, desarrolladores junior y personas que están buscando una oportunidad laboral.

## Objetivo general

Desarrollar una aplicación web full stack que permita registrar, organizar y analizar postulaciones laborales.

## Funcionalidades principales

- Registro e inicio de sesión.
- Creación de postulaciones.
- Consulta, edición y eliminación de postulaciones.
- Seguimiento por estados.
- Historial de cambios.
- Dashboard de estadísticas.
- Búsqueda y filtros.
- Tablero de seguimiento.

## Estados de una postulación

- Guardada.
- Aplicada.
- Entrevista.
- Prueba técnica.
- Oferta.
- Rechazada.
- Retirada.

## Tecnologías

### Frontend

- React.
- Vite.
- Tailwind CSS.
- React Router.
- Axios.

### Backend

- Node.js.
- Express.
- Prisma ORM.
- JWT.
- bcrypt.

### Base de datos

- PostgreSQL.

## Alcance del MVP

La primera versión permitirá que cada usuario administre sus propias postulaciones y consulte estadísticas básicas de su proceso de búsqueda laboral.
