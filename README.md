# JobTrack

JobTrack es una aplicación web para gestionar y hacer seguimiento a postulaciones laborales.

## Problema

Las personas que buscan empleo suelen aplicar a múltiples vacantes y pierden el control de las empresas, fechas, plataformas y estados de cada proceso.

## Solución

JobTrack permite registrar postulaciones, clasificarlas por estado, consultar métricas y hacer seguimiento al proceso de búsqueda laboral.

## Público objetivo

Estudiantes, practicantes y desarrolladores junior que buscan su primera oportunidad profesional.

## Funcionalidades del MVP

- Registro e inicio de sesión.
- Gestión de postulaciones.
- Estados de seguimiento.
- Tablero visual.
- Dashboard con estadísticas.
- Búsqueda y filtros.

## Tecnologías previstas

- Prisma
